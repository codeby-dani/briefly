# Phase 7 — Demo and Submission

**Window:** T+8:30 → T+10:00 · **Cuttable:** no

**Submit by T+9:30.** The last thirty minutes are buffer, not workspace.

## Status

- [ ] README rewritten from the Vite template
- [ ] Repo made public
- [ ] Demo video recorded, under 3:00, with audio
- [ ] Video uploaded to YouTube, public, link recorded
- [ ] Devpost text description finalised
- [ ] Devpost entry submitted

## Tasks — in this order

1. **README first**, before recording. It is the only artifact that stays
   useful if the recording goes badly, and it takes fifteen minutes:
   what it is, the live URL, how to enable WebMCP in both environments, the
   tool catalog, what is real and what is seeded, provenance, and the licence.
2. **Make the repo public.** Confirm `LICENSE` renders on the repo home page.
   Clear blocker B5.
3. **Record.** Follow `99-demo-script.md`. Two takes minimum. Audio is required
   by the rules — check the mic level on take one before recording take two.
4. **Upload to YouTube as public.** Not unlisted. Verify the link in a private
   window; a video that only plays while you are signed in is a failed
   submission.
5. **Devpost form.** Paste the description from `03-hackathon-compliance.md`,
   refined. Attach the live URL, repo URL, video URL.
6. **Submit.** Then re-open the submission and read it back.

## Exit Criteria

1. All four required artifacts exist and are reachable from a signed-out
   private window.
2. Video runs under 3:00 with audible narration.
3. Devpost entry is submitted, and the confirmation is visible.
4. The live URL still works after the final deploy — check it *after*
   submitting, not before.

## The Failure Modes That Actually Happen

Each of these has ended real entries:

- The video is unlisted, or set to public but still processing at the deadline.
  Upload with thirty minutes to spare and check it signed out.
- The repo is still private. A judge sees a 404 and scores zero.
- The last deploy broke the live URL and nobody re-checked after submitting.
- The submission was started at the deadline instead of finished by it.
- The mic was muted for the whole take and nobody played it back.
